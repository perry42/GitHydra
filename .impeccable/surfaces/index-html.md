Mode: Persuade.

Audience/job: a developer evaluating whether to install a free desktop git client, arriving via
search, a shared link, or a GitHub click-through. Action: download or open the repo. Proof/content:
all seven real shipped v1 features, real download links (GitHub Releases), GPL-3.0-or-later, the
any-host/no-sign-in/no-telemetry/no-paywall principles, one real captured app screenshot. No
fabricated stats, testimonials, or ranking claims (spec Non-goals, specs/landing-page-design-seo.md).

Chosen direction: Transit/rail wayfinding, extended from the app's own in-app commit-graph
metaphor (DESIGN.md THESIS) into this marketing surface. Assigned by concept-seed.mjs
(--scope direction --mode persuade, seed key 376702ae, assigned index 4 of 7 self-generated
grounded candidates) and confirmed by the user over two competitive alternates (a river-delta
survey-map "Impeccable's pick" candidate, and a hand-drawn dev-zine challenger) plus the standing
category-standard exit. Memorable moment: the first viewport is a real route-line diagram with
GitHydra's seven shipped features as station stops, one enlarged "interchange" stop revealing a
real captured app screenshot inline — the page demonstrates the transit-map claim about the
product by being built the same way, rather than describing it in prose.

Reused verbatim from DESIGN.md (this is a redesign of an unconsidered placeholder page, not a new
product identity): chrome/ink tokens, the accent, the validated 8-slot branch-lane categorical
palette (reserved here for literal route lines, never decoration), monospace-for-identifiers /
sans-for-prose split, dark-graphite-default-with-validated-light-equivalent theming.
New for this surface only: a display typeface with real signage/technical character (IBM Plex
Sans, self-hosted via Google Fonts — the DESIGN.md app itself intentionally uses only system-ui,
which craft-floor.md bans as an own-world display voice for a Persuade surface), IBM Plex Mono
pairing it for identifiers, and the wayfinding compositional grammar itself (route line, station
roundels, an interchange reveal, a "departures board" platform/download section) — none of this
exists in the app's own DESIGN.md and is native to this surface only.

Unresolved at brief time, resolved during build: exact screenshot content/theme(s) captured
against a clean demo fixture repo (delegated to ui-graphics in parallel with page construction);
whether the route line is a static SVG or has a drawn-on-scroll signature interaction (decided at
build: static-with-one-authored-scroll-reveal, per craft-floor's "one authored moment" motion rule
and new-work.md's "author motion as material" — the line draws itself in on first scroll, once).
