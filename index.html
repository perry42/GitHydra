GitHydra

A free, open-source, GitKraken-style visual git client — no sign-in, no telemetry, no host lock-in.

Download latest release View source on GitHub
  • Commit graphVisualize branch topology and merges at a glance.
  • Stage & diffStage, unstage, discard, and commit with a real diff view.
  • Branch managementCreate, switch, delete — local and remote-tracking.
  • Merge & rebaseFull conflict-resolution UI, not just a text editor.
  • Stash & cherry-pickSingle and multi-commit cherry-pick, with sequencer support.
  • Blame & historyPer-line authorship and file evolution.
  • Works with any git host — GitHub, GitLab, Bitbucket, self-hosted, bare repos — or no host at all.
  • No forced account creation, no telemetry by default, no feature paywalls.
  • Runs entirely against your local git and your own remotes — no proprietary backend.
  • Licensed GPL-3.0-or-later — free as in freedom, always.
